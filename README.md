# Mock Gen

A Go tool that generates mock implementations for all interfaces in a source file.

The input file must be inside a Go module (a directory tree containing a `go.mod` file). mock_gen resolves types and imports relative to the source file's module, so it can be invoked from any working directory.

## Installation

```shell
go install github.com/ArtHustle/moc_gen/cmd/mock_gen@latest
```

## Usage

```shell
mock_gen [flags] <source_file.go>
```

By default, the output is written to `./test/<source_file>_mock.go` relative to the input file.

It can also be executed with `go run`:

```bash
go run github.com/ArtHustle/moc_gen/cmd/mock_gen@latest -- [flags] <source_file.go>
```

## Options

| Flag | Short | Description |
|------|-------|-------------|
| `--output` | `-o` | Custom output file path |
| `--generate-return-handler` | | Adds a `func` field per method that, when set, is called instead of returning the static return fields |
| `--thread-safe` | | Wraps every method with a `sync.Mutex`; getters/setters take/release the lock |
| `--template` | `-t` | Path to a custom Go `text/template` file for code generation |
| `--no-header-note` | | Omits the `// Code generated by MockGen. DO NOT EDIT.` header |

## Example

Given `service.go`:
```go
package product

import (
	"context"

	"your/project/internal/service/product/model"
)

type Service interface {
	GetProductByID(ctx context.Context, productID model.ProductID) model.Product
}
```

Running:
```shell
mock_gen service.go
```

Produces `test/service_mock.go`:
```go
// Code generated by MockGen. DO NOT EDIT.

package test

import (
	"context"

	"your/project/internal/service/product/model"
)

type ServiceMock_GetProductByID_Call struct {
	Ctx       context.Context
	ProductID model.ProductID
}

type ServiceMock struct {
	getProductByID_calls_log       []ServiceMock_GetProductByID_Call
	getProductByID_param_ctx       context.Context
	getProductByID_param_productID model.ProductID
	getProductByID_return_product  model.Product
}

func (this *ServiceMock) GetProductByID(ctx context.Context, productID model.ProductID) model.Product {
	this.getProductByID_param_ctx = ctx
	this.getProductByID_param_productID = productID
	this.getProductByID_calls_log = append(this.getProductByID_calls_log, ServiceMock_GetProductByID_Call{Ctx: ctx, ProductID: productID})
	return this.getProductByID_return_product
}

func (this *ServiceMock) GetProductByID_calls() []ServiceMock_GetProductByID_Call { /* ... */ }
func (this *ServiceMock) GetProductByID_call(i int) ServiceMock_GetProductByID_Call { /* ... */ }
func (this *ServiceMock) GetProductByID_param_ctx() context.Context { /* ... */ }
func (this *ServiceMock) GetProductByID_param_productID(value model.ProductID) { /* ... */ }
func (this *ServiceMock) GetProductByID_return_product(value model.Product) { /* ... */ }
func (this *ServiceMock) Reset_history() { /* ... */ }
```

Same-package types (value types, slices, pointers) are fully supported and automatically qualified with the source package import path in the generated mock.

The shape is method-based by default: fields are unexported and accessed through generated getters/setters, every method gets a full call-recording log (see [Call Recording](#call-recording)), and adding `--thread-safe` later only adds internal locking — the API surface is identical.

## Return Handler

With `--generate-return-handler`, each method with return values gets an additional `func` field. When set, the function is called instead of returning the static fields:

```shell
mock_gen --generate-return-handler service.go
```

```go
type ServiceMock struct {
	add_calls_log    []ServiceMock_Add_Call
	add_param_a      int
	add_param_b      string
	add_return       func(int, string) (int, error)  // dynamic handler
	add_return_int   int                              // static fallback
	add_return_error error
}

func (this *ServiceMock) Add(a int, b string) (int, error) {
	this.add_param_a = a
	this.add_param_b = b
	this.add_calls_log = append(this.add_calls_log, ServiceMock_Add_Call{A: a, B: b})
	if this.add_return != nil {
		return this.add_return(a, b)
	}
	return this.add_return_int, this.add_return_error
}

func (this *ServiceMock) Add_return(value func(int, string) (int, error)) { /* ... */ }
```

The handler setter is write-only; there is no getter (callers don't read it back). Variadic params render as slices in the handler signature: `Log(values ...int)` produces `func([]int)`.

## Call Recording

Every method gets a full call log. Per method, the generator emits:

- An exported, public-field struct `<MockName>_<MethodName>_Call` holding one entry per call (one field per param, title-cased from the original param name, or type-derived for unnamed params).
- A `<MethodName>_calls() []<MockName>_<MethodName>_Call` getter returning the whole log (a defensive copy under `--thread-safe`).
- A `<MethodName>_call(i int) <MockName>_<MethodName>_Call` indexer (panics on out-of-range; standard slice semantics).
- A single `Reset_history()` on the mock that zeroes every per-method log without touching installed handlers or armed static return values.

The log is appended inside the lock under `--thread-safe`, **before** any handler invocation. A handler that panics still leaves the call recorded.

Methods with no args produce an empty struct (`type ServiceMock_Process_Call struct{}`) and still get the slice-returning getter — the API stays uniform regardless of arity. Variadic params render as a slice (`...int` becomes `Values []int`).

```go
// "was Send called?"
require.Len(t, mock.Send_calls(), 1)

// "what was passed on the first call?"
c := mock.Send_call(0)
require.Equal(t, "user@example.com", c.Email.To)

// "all emails sent"
var emails []string
for _, c := range mock.Send_calls() {
    emails = append(emails, c.Email.To)
}

// reset the log between subtests, keep armed handlers/returns
mock.Reset_history()
```

### Breaking change in v0.7.0

This release removes the legacy public-field shape entirely. There is no `--method-api` flag — the method-based shape is the only shape. `<MethodName>_calls()` previously returned `int` (the call count); it now returns `[]<MockName>_<MethodName>_Call`. The count is `len(mock.Send_calls())`.

To migrate:

```go
// before
n := mock.Send_calls                 // public int field
mock.Send_return_string = "hello"    // public field assignment

// after
n := len(mock.Send_calls())          // method call
mock.Send_return_string("hello")     // setter method call
```

### Migration example: hand-rolled fake → generated mock

A 250-line hand-rolled fake that combined call recording, per-method error injection, per-method return-value override, per-call hooks, and passthrough-to-real-impl collapses to a few lines on a `--thread-safe --generate-return-handler` mock:

```go
fake := &mocks.RuntimeMock{}

// passthrough fallback
fake.Activate_return(func(ctx context.Context, t *workflow.Trigger) error {
    return real.Activate(ctx, t)
})

// arm an error
fake.Activate_return_error(errors.New("boom"))

// observation hook + delegate
fake.Activate_return(func(ctx context.Context, t *workflow.Trigger) error {
    observeBeforeCall(t)
    return real.Activate(ctx, t)
})

// assert
calls := fake.Activate_calls()
require.Len(t, calls, 2)
require.Equal(t, "trig-1", calls[0].T.ID)
require.Equal(t, "trig-2", calls[1].T.ID)
```

No `Set*Error`, no `Set*Hook`, no custom `*Calls()` slices, no custom `Reset()` — all of that is generated.

## Thread-Safe Mocks

With `--thread-safe`, a `sync.Mutex` is added and getters/setters take/release it. The exported API is identical to the default; only internal locking changes.

```shell
mock_gen --thread-safe service.go
```

```go
type ServiceMock_Add_Call struct {
	One int
}

type ServiceMock struct {
	mu sync.Mutex

	add_calls_log     []ServiceMock_Add_Call
	add_param_one     int
	add_return_string string
}

func (this *ServiceMock) Add(one int) string {
	this.mu.Lock()
	this.add_param_one = one
	this.add_calls_log = append(this.add_calls_log, ServiceMock_Add_Call{One: one})
	_r0 := this.add_return_string
	this.mu.Unlock()

	return _r0
}

func (this *ServiceMock) Add_calls() []ServiceMock_Add_Call { /* defensive copy under lock */ }
func (this *ServiceMock) Add_call(i int) ServiceMock_Add_Call { /* ... */ }
func (this *ServiceMock) Add_param_one() int { /* ... */ }
func (this *ServiceMock) Add_return_string(value string) { /* ... */ }
func (this *ServiceMock) Reset_history() { /* zeros every per-method log */ }
```

### Combining with `--generate-return-handler`

When both flags are set, install a handler with `mock.Add_return(handler)`:

```go
mock := &ServiceMock{}
mock.Add_return(func(one int) string {
    return fmt.Sprintf("got %d", one)
})
```

The mutex is **released before the handler runs**. The generated method snapshots the handler reference and any static fallbacks under the lock, unlocks, and only then invokes the handler. A handler can safely call back into the same mock — install a new return value, read call counts, invoke another method — without deadlocking. A handler installed by `mock.Add_return(newHandler)` mid-flight only takes effect on the next call; the in-flight call uses the snapshot.

The mock's mutex protects only the mock's own fields. A handler that captures external state must guard that state itself if the system under test is concurrent.

## Custom Templates

You can replace the built-in template with your own Go `text/template` using `--template`. The template receives a `MockData` struct and its output is run through `gofmt`.

### Data Model

```go
type MockData struct {
    HeaderNote string       // "// Code generated by MockGen. DO NOT EDIT.\n\n" or ""
    Imports    ImportsData
    Interfaces []InterfaceData
    Options    Options
}

type ImportsData struct {
    StdImports    []string   // e.g., "\"context\"", "\"sync\""
    NonStdImports []string   // e.g., "\"github.com/foo/bar\""
}

type InterfaceData struct {
    Name     string       // e.g., "Service"
    MockName string       // e.g., "ServiceMock"
    Methods  []MethodData
}

type MethodData struct {
    Name             string
    CallStructName   string             // e.g., "ServiceMock_Add_Call"
    CallStructFields []FieldData        // public, title-cased fields — one per param
    CallsLogField    string             // unexported log slice field, e.g. "add_calls_log"
    CallByIndexName  string             // singular indexer method name, e.g. "Add_call"
    Params           []FieldData
    ReturnHandler    *ReturnHandlerData // non-nil when --generate-return-handler and method has returns
    Returns          []FieldData
    Signature        SignatureData
    Getters          *GetterData
}

type FieldData struct {
    Name string  // e.g., "add_param_one" (mock field) or "One" (Call struct field)
    Type string  // e.g., "int", "*http.Request"
}

type ReturnHandlerData struct {
    FieldName   string  // e.g., "add_return"
    ParamTypes  string  // e.g., "int, string"
    ReturnTypes string  // e.g., "string, error"
}

type SignatureData struct {
    Params       string    // e.g., "one int, two string"
    Returns      string    // e.g., " (string, error)"
    ParamNames   []string  // e.g., ["one", "two"]
    ReturnFields []string  // e.g., ["this.add_return_string"]
}

type GetterData struct {
    CallsGetter   GetterMethod   // Method_calls() returns []<MockName>_<MethodName>_Call
    CallByIndex   *GetterMethod  // Method_call(i int) returns one <MockName>_<MethodName>_Call
    ParamGetters  []GetterMethod
    ReturnSetters []SetterMethod
    HandlerSetter *SetterMethod  // non-nil when --generate-return-handler AND method has returns
}

type GetterMethod struct {
    MethodName string
    FieldName  string
    ReturnType string
}

type SetterMethod struct {
    MethodName string
    FieldName  string
    ParamType  string
}

type Options struct {
    GenerateReturnHandler bool
    MakeThreadSafe        bool
    AddHeaderNote         bool
    CustomTemplate        string
}
```

### Example: Spy Pattern

A template that records all calls in a single slice keyed by method name:

```shell
mock_gen --template spy.tmpl -o service_spy.go service.go
```

`spy.tmpl`:
```go
package test

{{if or .Imports.StdImports .Imports.NonStdImports}}import (
{{range .Imports.StdImports}}	{{.}}
{{end}}{{if and .Imports.StdImports .Imports.NonStdImports}}
{{end}}{{range .Imports.NonStdImports}}	{{.}}
{{end}})
{{end}}

{{range $iface := .Interfaces}}
type {{$iface.MockName}}Call struct {
	Method string
	Args   []any
}

type {{$iface.MockName}} struct {
	Calls []{{$iface.MockName}}Call
{{range $iface.Methods}}{{range .Returns}}	{{.Name}} {{.Type}}
{{end}}{{end}}}

{{range $method := $iface.Methods}}func (this *{{$iface.MockName}}) {{$method.Name}}({{$method.Signature.Params}}){{$method.Signature.Returns}} {
	this.Calls = append(this.Calls, {{$iface.MockName}}Call{Method: "{{$method.Name}}", Args: []any{ {{range $i, $pn := $method.Signature.ParamNames}}{{if $i}}, {{end}}{{$pn}}{{end}} }})
{{if $method.Returns}}	return {{range $i, $rf := $method.Signature.ReturnFields}}{{if $i}}, {{end}}{{$rf}}{{end}}
{{end}}}
{{end}}{{end}}
```

### Accessing the Built-in Template

The built-in template is available programmatically as a starting point for customization:

```go
import mock_gen "github.com/ArtHustle/moc_gen"

template := mock_gen.DefaultTemplate()
```

## Programmatic Usage

```go
import mock_gen "github.com/ArtHustle/moc_gen"

// From a file path (must be inside a Go module)
content, err := mock_gen.GenerateMockFileWithOptions("service.go", mock_gen.Options{
    AddHeaderNote:         true,
    GenerateReturnHandler: true,
})

// From source string (for testing or embedding)
content, err := mock_gen.GenerateMockContentWithOptions(sourceCode, mock_gen.Options{})
```
